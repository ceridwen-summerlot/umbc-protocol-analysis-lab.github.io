# Glossary
  Asymmetric Encryption - An encryption method that uses two different keys—a public key and a private key—to encrypt and decrypt data. <br>
  <br>
  CPSA - Cryptographic Protocol Shapes Analyzer Tool <br>
  <br>
  Cryptography - The practice and study of techniques for secure communication in the presence of adversarial behavior <br>
  <br>
  Decryption - The process of translating unreadable, encrypted data (ciphertext) back into its original, understandable format (plaintext) <br>
  <br>
  Encryption - The process of scrambling readable data (plaintext) into an unreadable format (ciphertext) using a mathematical algorithm and a key <br>
  <br>
  Protocol - A set of rules that allows two or more entities to transmit information <br> 
  <br>
  Symmetric Encryption - An encryption method that uses a single key to encrypt and decrypt data <br>
  <br>
